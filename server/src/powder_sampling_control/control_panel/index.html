闭环加粉 dispensing_algorithm · 天平闭环 · 振动+推杆

算法层原样复用（观测进、决策出），这里是硬件绑定层：天平质量 → 运动观测器 → 振幅闭环 v6（延迟补偿 + 事件驱动：纯滞后 τ 与落料周期 T 从落料阶跃在线估计，判据只看「上次调幅 + τ」之后的生效窗；速率正在回升时先等——上一发的效果还在路上不叠加；有流量只微调 标定振幅 ±0.2V，偏慢 3s 起进丝滑爬坡（标定±0.5V 带内：有出粉 +0.08V/4s、速率为0 +0.12V/3s，有出粉绝不脉冲冲击）；整个生效窗一粒粉没落 = 卡粉/断料，快加/粗加爬到带顶仍断料才踢一脚救济（振幅瞬间抬到 标定+1V 持续 0.5s 后回落，一脚没踢开下一脚再 +0.5V），硬顶 标定值 +1.5V，到顶提示查料斗；慢加与慢加的踢脚规则不变，追速率依旧禁止，只有恢复出料的救济通道）+ 控制器（只做预测停车判定）。三个阶段可以逐段配置你自己标定过的参数：快加（大头：≤5000 到 75%、>5000 冲到剩余 800mg，追速度不管稳不稳）→ 粗加（跟得上又不太毛躁）→ 慢加（低幅收尾、预测停车）。推杆只在阶段入口开到该段开度，整段锁死不动，收尾也不复位；频率/占空比跟着所选粉末的标定走（失水剂1 = 80Hz/22%，膨润土 = 80Hz/50%，没标定的粉才用默认 80Hz/50%）——换粉千万别忘了这组参数，它是速率曲线的前提。运行中振动与推杆由控制器接管，手动按钮全部锁定；「停止」与急停永远可用。目标 100–20000 mg，验收 ±10 mg。切段沉降门：切出速率 ≥ 本段规定速率×1.5（粗加 20→30mg/s、快加 75→112.5mg/s；页面填了数就用绝对值）时先停振等余料落完再换段（搅拌和推杆保持不动）；并且「当前质量 + 速率×1s」够到切点就提前停振，让余料正好落在切点上（预测尾量切段）；每次"停振后还落了多少"记进粉体档案，下次自动把切换点提前——重粉不加这一步，余料会把粗加/慢加顶穿。「当前质量」从起振到收尾、结束以后一直实时读天平（收尾沉降的那几秒也不再冻住），结束停稳后显示的就是最终净重。

粉末标定（开环前馈） 速率表 → 粉体库 feedforward_v2

选粉末 → 设定搅拌转速和推杆开度（各填你自己的一个值）→ 开环喷 T 秒，用振动期间的天平斜率算出这种粉在这个工况下能出多少粉。结果写进 data/powder_library/<粉名>.json，闭环加粉时按阶段目标速率去这张表里挑工作点——挑中哪个点，搅拌转速和推杆开度都照抄它，推杆整段锁死、速率只靠振幅调。每个点都会记下当时的频率 / 占空比 / 振幅，每次标定另存一份 runs/calib_*.json 便于逐点对账。频率和占空比按粉记住：选已标定的粉会自动填成它当初那组（如失水剂1 是 80Hz/22%、膨润土 80Hz/50%），闭环加粉也按这组下发。标定会真实出粉：默认 1 点、每点 20 秒（新粉默认方波 80Hz / 50% / 2Vpp，搅拌 100 RPM / 推杆 600），含沉降约 45 秒。多点扫描会按点数累加时间与出粉量。

标定管理 删无效标定点 · 立即重算前馈表

标定表里有的点根本不能用：料斗搭桥/没料测出来的速率 0、曲线抖动过大的 CV > 40%、天平被碰导致的负速率——这些点留在表里会把「挑工作点」带歪（加粉时可能挑到塌料点，转速和开度都是错的）。这里按点删，删完马上重算三阶段搅拌转速与速率区间（档案里其它历史字段不动）。红色行 = 判为不可信（右侧给出原因）。注意：runs/calib_*.json 里的历史归档不会跟着删，那是原始记录，删了没法对账。
