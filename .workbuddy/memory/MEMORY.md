# 粉末加样项目 — 长期要点

## 硬件（实测）
- 搅拌 ZDT Emm42（COM9,0x01,115200,私有0x6B）：0–3000RPM，>1300 需 acc≥200 曲线启动；减速停=写"速度0+acc"，
  **acc 仅 0..255**（300 会让停止失效）。堵转锁存，清 `01 0E 52 6B`。错误应答 `地址+00+EE+校验` 必须报错。
- 升降 双 MD30（COM10,1+2）必须同步：广播地址 **0x00**（255 无效），速度/位置帧隔 ≥50ms，轮询 ≥100ms；
  行程 20–980，速度固定；偏差>5 拒动 / 0.35s 未离位急停 / 运行中看门狗急停。
- 推杆 因时 LA（COM10,ID=3，55AA/AA55）：0–2000，500 单位≈0.6s，±1；error 只看 bit0–3；驱动 `la_uart_protocol.py`。
- 给料 振动料斗 QLS3600S（COM16，0.01–20Vpp）；天平 AT8811C（COM11），1count=1mg。

## 铁律
1. 运行中不改代码；重启前确认 `dispense.running=False`、`calib.running=False`。
2. 让机构运动的测试先征得同意；改完只做只读验证。
3. **推杆硬约束**：只来自标定点照抄/页面手填，段内锁死；收尾与标定结束都不复位。
4. **速率唯一调节量=振幅**；占空比按段固定；慢加只恢复出料、不追速率。
5. 快加/粗加必须真追速率（少了加、快了减）。
6. **段振幅基准 = 页面那一行（留空 = 3.0 / 2.5 / 2.0）**，不再是粉体标定振幅（2026-10-23 18:36 用户定）。
7. 用完猝发必须 `sig.burst_off()`；可调参数不许只读；标定默认只跑一个工作点；新驱动注释中文。
8. **口径**：说「每一次加粉」/「这一次加粉」/「本次加粉」，**任何场合都不许出现「炉」字**
   （2026-10-26 定，2026-10-27 17:15 用户重申"语言上全得改"）。范围包括：对话回复、界面文案、
   运行日志、代码注释与 docstring、汇总脚本输出与表头、报告。已有词表：这一炉→这一次加粉、
   本炉→本次加粉、上一炉→上一次加粉、同一炉→同一次加粉、每炉→每次加粉、那炉→那次加粉、
   炉次→加粉次数、炉数→加粉次数、开炉→开始加粉、起炉基线→开始加粉前的基线。

## 阶段规则（只改 `stage_boundaries`）
- >5000：快加→−800、粗加→−100；1000–5000：75%/95%（或 −100）；300–1000：粗加→目标−预留(15%,50–150)；<300：−40。
  慢加目标=剩余/18s（≤1.6×靶子）。**慢加正常只占 5–15%**。
- 切点由页面「加料」列提交，后端不现算。改目标没等重算就点开始＝沿用上一次加粉的切点（1812mg 就进慢加那次）；
  页面 `lastPlanFilledTarget` 核对+自动重算，后端慢加剩余 >max(30%,150mg) 报警。
- **沉降门期间质量必须实时记**（2026-10-23 18:59 用户指出"切段沉降门的时候不更新质量，
  导致很多次最后粗加加过头"）：旧版 while 里不调 `_record`，页面/曲线/CSV 冻在切段那一刻，
  实际还在落（今天 29 次切段余料均值 **40mg**、最大 89mg）。现在每 0.12s 记一拍（stage=`gate`，
  `STAGE_TEXT` 有"沉降等待"）并每 0.5s 补曲线点。余料顶穿下一段切点 → while 跳段；
  已进验收带（≥目标−10）→ 直接收尾，不再开新段的推杆/振幅。
- **收尾称重同样实时记**（2026-10-26 补）：`_settle` 每拍 `_record(stage="settle", learn=False)`
  并刷新状态栏"收尾称重 X/Y mg"；实测最后 2–4s 还能涨 10–30mg，旧版页面看不到。
- **沉降门门槛按段算 + 预测切段**（2026-10-26 11:05 用户定）：触发门槛 = **本段规定速率 ×1.5**
  （快加 75→112.5、粗加 20→30、慢加 5→7.5 mg/s），页面「触发速率」填数才用绝对值。
  另加 `_predictive_cut`：**质量 + 速率×1s ≥ 切点就提前停振**（force 走沉降门，不受门槛拦）。
  预测提前量要减掉 `switch_compensation_mg`（档案学到的惯性落料已把切点提前过），
  不叠加——所以有历史的粉（封堵剂1 粗加>慢加 comp=50）仍然靠提前切点，新粉才靠预测。
  `_record(..., learn=False)` = 只显示不学习：沉降/收尾/缓补等落定相位了起振门槛与 τ 会被余料带偏。
- **沉降门判稳（2026-10-27 11:35 修 bug）**：硬上限 `SETTLE_GATE_MAX_S` **1.2→8.0**；判稳 =
  **一个落料周期内净增重 ≤2mg**，周期 = clamp(T_est, 2, 5)s（旧判据 0.5s 窗极差≤2mg 等于没判稳，
  实测每段都"1.2s 到点 + stable=False"硬切，余料 +52~127mg 全落进下一段）。
  漏料型粉：停振 2s 后近 1.2s 仍 ≥3mg/s → 连搅拌也减速停（上限 +4s，进段会重新起转）。
  到上限仍未稳 → 照切但日志打 ⚠"下一段是踩着余料起振的"。超速熔断的等落定**仍是 0.5s 短窗**（未改）。

## 振幅闭环
- 每段区间：快加/粗加 **基准 ±0.5V**（3.0→2.5–3.5 / 2.5→2.0–3.0），**慢加 0.01–2.5**
  （下界 = 设备绝对下限，2026-10-27 用户删掉 1V 下限，`AMP_MIN_VPP=0.01`），单步 0.05–0.15V：
  Δu=(目标速率−预测速率)/k_est；预测=6s 回归均速+加速度×min(τ,3s)；死区 max(1.5,目标×8%)；超调减半；
  响应窗锚 `_amp_last_write_s` 3s，6s 零落料按 rate=0 延到 3.5s。
- 踢脚 gate：到带顶 + 停 4s + 该窗 <1mg/s 才踢（0.5s@基准+1V，没踢开 +0.5V，顶 +1.5V）。
- **踢脚只是脉冲，踢完回踢前振幅，绝不改工作点**（2026-10-27 11:44 用户："触发完回到
  原来的幅度即可，不需要记忆这个阶跃触发了门槛学习"）。观察窗 + "上移到踢脚−0.2V"
  + `_amp_threshold_est` 门槛学习**已整体删除**，别再加回来。病案：11:43 那次加粉粗加
  基准 1.5V，踢过一次后振幅 1.27→3.0V 调 9 次、末值 2.8V，实测 11.93mg/s（目标 20）。

  就是我会输入的那个值"）。`_amp_threshold_est`（实测"落得下粉的最低振幅"）**仅记录、不参与控制**：
  起步振幅 = 本段基准、闭环下界 = 带下界、提前降幅目标 = 下一段基准，三处都不再用它。

- **真机主循环周期实测 0.266s**（标称 `SAMPLE_INTERVAL_S=0.12`，读秤+串口+控制器开销；

  惯性当本段起点"→ 一开段就 6 倍速 → 切段余料顶穿慢加。

  最终差 62mg 转补差。
  **仍然留着的问题**：短段（<4s）沉降门测不出速率 → 默认"不停振"，段间只有几十 ms 的关闸，
  没有真正等料落定。要彻底解决得让"测不出速率"时按 force 走沉降门（未改，待用户定）。

## 缓补（trim pulse）
- **熔断 = 提前切段，绝不进缓补**（2026-10-26 18:35 用户："熔断只发生在阶段切换之间就行了"）。
  `_surge_brake` 停振后若又落 ≥`SURGE_ADVANCE_MG=60`（料道还在塌）→ 置 `_surge_advance`，
  主循环顶部把它当成**第三个切段触发**（与"质量到切点""预测切点"同级）：关段账 → 沉降门 →
  进下一段配方。振动保持关闭，下一拍 `continue` 立刻切段，由 `_enter_stage` 重开振动；
  已是最后一段则重新起振继续（否则会断料中止）。旧版 `to_pulse`（26% 进度跳"缓补"、
  单发 ~100mg、绕过粗加/慢加）已删除。
- 缓补只有两个入口：**慢加剩 ≤40mg 正常进**、判停偏轻补差（`source=topup`，记 `trim_source`）。
- **缓补存粉保护**（2026-10-28 14:30 用户，抑制剂 3000mg +52 病案：断流时搅拌一直转、
  存粉挂料道，判停差 3mg 收尾却 +52）：入口泄料 ≥`TRIM_STOCK_GAIN_MG=15` 触发——
  每发**不起搅拌**（搅拌一丢存粉倾泻）、振幅降 1.0V 起步、没出粉每发只 +0.2V、
  出了粉就停那档（退档/降档/发前降档全跳过）；连续 8 发一粒不出 → 恢复原振幅转正常脉冲。

  stir_stop"把 0.4s 串口时间藏住了：那次加粉 1978→2048 的 +70mg 全落在这段黑箱里，一读数
