# 粉末加样项目 — 长期要点

## 硬件（实测）
- 搅拌 ZDT Emm42（COM9,0x01,115200,私有0x6B）：0–3000RPM，>1300 需 acc≥200；减速停=写"速度0+acc"，acc 只 0..255。
  堵转锁存，清 `01 0E 52 6B`；错误应答 `地址+00+EE+校验` 必须报错。
- 升降 双 MD30（COM10,1+2）必须同步：广播地址 0x00（255 无效），速度/位置帧隔 ≥50ms，轮询 ≥100ms；
  行程 20–980，速度固定 8；偏差>5 拒动 / 0.35s 未离位急停 / 运行中看门狗急停。
- 推杆 因时 LA（COM10,ID=3,55AA/AA55）：0–2000，500 单位≈0.6s，±1；error 只看 bit0–3。
- 给料 QLS3600S（COM16,0.01–20Vpp）；天平 AT8811C（COM11,9600），1count=1mg。
- 串口：COM9/10 与 COM11 是三条 FTDI（6015/6015/232R），COM16 是 CH340。若端口能打开但**零回包**，
  先查设备供电与线缆，别怀疑端口号（2026-11-10 实测：三条 FTDI 在 9600/115200 下对 MD30/天平/ZDT
  帧全部零回应，交叉发帧也不是端口错位）。

## 铁律
1. 运行中不改代码；重启前确认 `dispense.running=False`、`calib.running=False`。
2. 让机构运动的测试先征得同意；改完只做只读验证。
3. 推杆硬约束：只来自标定点照抄/页面手填，段内锁死；收尾与标定结束都不复位。
4. 速率唯一调节量=振幅；占空比按段固定；慢加只恢复出料、不追速率。
5. 快加/粗加必须真追速率（少了加、快了减）。
6. 段振幅基准 = 页面那一行（留空 = 3.0/2.5/2.0），不是粉体标定振幅。
7. 用完猝发必须 `sig.burst_off()`；可调参数不许只读；标定默认只跑一个工作点；新驱动注释中文。
8. 口径：只说「每一次/这一次/本次加粉」，**任何场合都不许出现「炉」字**（界面、日志、注释、报告）。
   `grep -rn "炉" server/src lab web` 应为空。
9. 搅拌方向一次加粉一换：`server/data/stir_direction.json` 的 `next_direction`（0顺/1逆）；
   `take_stir_direction()` 在真正起转时取值并翻档，一次加粉内所有起转共用同一方向，没转起来不消耗，
   手动面板不参与交替。

## 工况默认（改要三处对齐）
- 方波 80Hz/50%；标定默认 2Vpp/100RPM/杆600/每点20s（`rate_calibration.DEFAULT_*` 唯一源）。
- 三阶段目标速率 75/20/5 mg/s、振幅 3.0/2.5/2.0 Vpp；目标 100–20000mg。
  改默认要动：后端常量 + plan/前端 `DISP_STAGE_AMP_DEFAULT` 与三行 `s-amp` 的 value。
- 标定保护：瞬时 300mg/s、单点 6000mg；每点停振与搅拌减速停同时下发、不回位。

## 粉级标记 `dispense_flags`
- `zero_rate_pulse:false`：速率为 0 时不许踢脚脉冲（目前只有封堵剂2，起振即成团爆发）。
- `slow_amp_span_vpp:1.0`：慢加振幅带放宽到基准±1.0V（下界 1.0），作为"不许脉冲"的补偿。
- `rod_sweep:{"step":25,"interval_s":4.0,"dwell_s":0.3}`：加粉中振动开着时每 4s 推杆
  base→+25→−25→**必回 base**，持 `_rod_wiggle_lock`、`_applied_window` 复位；沉降门/收尾/缓补不滑；
  离切点或目标剩 `ROD_SWEEP_KEEP_OFF_MG=50` 停滑。目前只有大分子包被剂。±50 已全清（断料滑窗与
  页面「推杆微滑」都改 25）。
- 页面「断料脉冲」开关只能收紧：粉档 false 时页面打开也无效。

## 阶段与切段
- 切点：>5000 快加→−800、粗加→−100；1000–5000 75%/95%；300–1000 粗加→目标−预留(15%,50–150)；
  <300 −40。慢加目标=剩余/18s（≤1.6×靶子），正常只占 5–15%。
- 切点由页面提交、后端不现算；改目标没重算就点开始＝沿用上次切点（页面 `lastPlanFilledTarget` 兜底）。
- 沉降门期间必须实时记质量（每 0.12s 一拍，stage=`gate`），收尾称重同样实时记（stage=`settle`）——
  旧版不记录，页面/曲线冻在切段那一刻，实际还在落（余料均值 40mg、最大 89mg），粗加就过头。
- 沉降门门槛 = 本段规定速率×1.5；`_predictive_cut`：质量+速率×1s ≥ 切点就提前停振，
  提前量要减 `switch_compensation_mg`（不叠加）。
- 判稳：硬上限 `SETTLE_GATE_MAX_S=8.0`，判稳 = 一个落料周期 clamp(T_est,2,5)s 内净增 ≤2mg；
  漏料型粉停振 2s 后仍 ≥3mg/s → 连搅拌也减速停。超速熔断的等落定仍是 0.5s 短窗。
- 进段时序 = 先关闸 → 改配方 → 最后开闸（`_enter_stage` 末尾才 `sig_output(True)`）。
  遗留：短段(<4s)测不出速率时默认不停振，段间没有真正等料落定（待用户定）。

## 振幅闭环
- 快加/粗加 基准±0.5V；慢加 0.01–2.5V（`AMP_MIN_VPP=0.01`）。单步 0.05–0.15V；
  Δu=(目标速率−预测速率)/k_est；预测=6s 回归均速+加速度×min(τ,3s)；死区 max(1.5,目标×8%)。
- 踢脚只是脉冲：踢完回踢前振幅，绝不改工作点、不记阶跃；观察窗与门槛学习已整体删除，别加回来。
- 起振门槛 = 用户在页面填的那个振幅；`_amp_threshold_est` 仅记录、不参与控制。
- 慢加幅度必须能往下走：升幅只恢复出料（≤0.10V/次、上限 +0.5V），降幅单步 0.30V、下界 基准−1.0V。
- 真机主循环周期实测 **0.266s**：短窗判据一律 ≥3 点 + span≥0.30s（旧的 0.7s/4 点判据让超速熔断长期失效）。
- `_entry_amp_guard` 进段压幅只对粗加。
- 断料提问（11-09 加）：速率为 0 超 `STALL_ASK_S=10` 弹窗三选一（提振幅上限 / 上下滑窗 / 停止加粉），
  超时 300s、每枪最多 4 次；`running` 属性含 waiting。

## 缓补（trim pulse）
- 熔断 = 提前切段，绝不进缓补；`_surge_advance` 是第三个切段触发。
- 入口只有两个：慢加剩 ≤40mg 正常进、判停偏轻补差（`source=topup`）。
- 入口三段：停振 → 搅拌保持 `TRIM_ENTRY_HOLD_S=1.2s` 观察 → 停搅拌 → 等落定（≤8s）。
- 脉冲时长恒定 `TRIM_PULSE_S=0.40`，只变幅度；没出粉抬 0.5V（顶 5.0），不许首发跳 4V。
- 抬档只是试探，出粉就退：>3V 出粉退到 `max(1.0, 当前−1.0)`；≤3V 不退。
- 单发 >18mg 算加多，同规则退；连 6 发 0mg 停手报"查料斗"。
- 存粉保护：入口泄料 ≥`TRIM_STOCK_GAIN_MG=15` 触发（不起搅拌、降 1V 起步、每发 +0.2V），
  8 发不出恢复原振幅转正常脉冲；退出分支必须真能退出（曾因 6<8 死锁）。
